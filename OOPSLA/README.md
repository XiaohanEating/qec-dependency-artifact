# QEC simulation experiments

See the repository [README](../README.md) for setup and [reproduction notes](../REPRODUCIBILITY.md) for the recorded protocols.

`src/semantics.py` contains the finite assembly model and dependency checks. `experiments/` contains source extraction, real artifact comparisons, reuse comparisons, physical sampling, cache comparisons, and tests. `gate_audit/` retains the initial component-extension audit. `research/` contains supplementary restricted source and consumer-relation experiments.

Run commands from the repository root. Regenerate experiment outputs into a separate directory with `--out DIR`.
