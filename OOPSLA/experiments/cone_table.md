## 4. Trigger-2 risk summary

**Verdict on the baseline `source_faithful`: bounded**  

Verdict on the published baseline `source_faithful`: **bounded** (0/240 substitutions unbounded, 240/240 certified applicable). Cone sizes on that baseline: code=[4], extractor=[2], arch=[1], noise=[1], decoder=[1]. The contrast columns isolate *why* an assembly can be unbounded: `clean` has 0/240 and `quits_dataflow` has 0/240, while the hand-built H1 counterexample `quits_faithful` has 48/240 — every one of them in the `extractor` dimension, because that component declares reads=('code',) while its registry lookup also reads the `extractor` coordinate, so (C1)/(C2) fail and Theorem 3 reports observed ⊄ declared. Faithfulness *alone* therefore does not cause unboundedness; an under-declared read set does.
